# SecPass

Менеджер паролей с аутентифицированным шифрованием AES-256-GCM,
защитой памяти и графическим интерфейсом.

## Возможности

- **Шифрование**: AES-256-GCM (целостность + конфиденциальность), ключи выводятся через Argon2id
- **Мастер-ключ**: случайный 32-байтовый, обёрнут ключом из пароля; пароль данных не шифрует
- **Защита памяти**: SecureString с рабочим mlock/VirtualLock, зануление ключей при блокировке
- **Ключ-файл**: 32 случайных байта (CSPRNG), обязателен при разблокировке, если использовался
- **Автоблокировка**: через 5 минут бездействия и при закрытии окна
- **Буфер обмена**: автоочистка через 30 секунд после копирования
- **Tamper-детект**: подмена/повреждение файлов хранилища обнаруживается
- **Атомарные записи**: крах или полный диск не повреждают хранилище
- **Группы**: древовидная структура, перетаскивание записей; пустые группы защищены
- **Генератор паролей**: CSPRNG (`secrets`), честная оценка энтропии
- **Вкладки**: работа с несколькими хранилищами одновременно

## Установка

```bash
git clone <repo>
cd secpass
python -m venv .venv
.venv\scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Отладка: `python main.py --debug` · Версия: `python main.py --version`

```

├── secure/          # SecureString (mlock/VirtualLock, zeroize)

├── log.py           # NullHandler-логгер (debug по флагу)
└── main.py          # Точка входа
```

## Криптография

```
Пароль ───────────────────────────────────────┐
Ключ-файл (опционально, SHA256) ──────────────┤
                                               ▼
                              Argon2id (соль 16 байт)
                               memory=64 MiB, iterations=3, lanes=4
                                    │
                                    ▼
                           KEK (32 байта, зануляется)
                                    │
                     оборачивает (AES-256-GCM) мастер-ключ
                                    │
                                    ▼
                   мастер-ключ (32 случайных байта, SecureString)
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        ▼                           ▼                           ▼
   head записи                 body записи                 group файл
   AES-256-GCM                 AES-256-GCM                 AES-256-GCM
   (nonce 12 байт + шифротекст + тег аутентификации)

Имена файлов:  SHA256(UUID) — без утечки содержимого
nonce:         CSPRNG, новый на каждое шифрование
целостность:   GCM-тег — подмена файлов детектируется
masterkey:     SPV2 | флаг ключ-файла | соль | nonce + GCM(KEK)
```

Формат данных жёстко версионирован (`SPV2`); хранилища других форматов
отклоняются при открытии.

## Безопасность

- Минимальная энтропия пароля: **80 бит**; мастер-пароль — от **12 символов**
- Пароли с повторяющимися символами штрафуются при оценке энтропии
- Пароли в памяти: `VirtualLock`/`mlock` + зануление при блокировке
- Автоблокировка 5 минут, очистка буфера обмена 30 секунд
- Атомарная запись (temp + fsync + replace), права `0600`
- Создание поверх существующего хранилища запрещено
- Имена файлов — SHA256(UUID), без утечки содержимого
