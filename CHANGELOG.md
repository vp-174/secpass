# Changelog

Все значимые изменения проекта SecPass.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии: [SemVer](https://semver.org/lang/ru/).

## [2.0.0] — 2026-07-20

Крупное обновление безопасности по результатам аудита: смена криптоформата,
реальная защита памяти, автоблокировка и строгие проверки целостности.

### Security

- **AES-256-GCM вместо AES-256-CBC**: все данные хранилища теперь
  аутентифицированы — подмена, перестановка и повреждение файлов
  детектируются (формат хранилища v2).
- **Поддержка формата v1 (AES-CBC) полностью удалена**: ранние сборки
  несовместимы, хранилища открываются только в формате v2 (`SPV2`).
- **Мастер-ключ обёрнут ключом Argon2id**: пароль/ключ-файл больше не
  используется для шифрования данных напрямую; производный ключ (KEK)
  зануляется сразу после разблокировки.
- **Ключ-файл из CSPRNG**: генерируется 32 случайных байта
  (`secrets.token_bytes`); существующие файлы никогда не перезаписываются.
- **Fail-closed для ключ-файла**: если хранилище создано с ключ-файлом,
  разблокировка без него отклоняется; флаг хранится в открытом виде.
- **Генератор паролей на CSPRNG**: `secrets.choice` вместо Mersenne Twister,
  который позволял предсказывать пароли.
- **Реальная блокировка памяти**: `VirtualLock` (Windows) / `mlock` (POSIX)
  с корректными ctypes-прототипами и проверкой результата; раньше защита
  молча не работала ни на одной платформе.
- **Зануление ключей при блокировке**: `lock()` очищает и мастер-ключ,
  и производный ключ (v1); повторные разблокировки не накапливают ключи.
- **Автоблокировка по бездействию** (5 минут) и блокировка при закрытии
  окна; на экране входа пароль очищается после каждой попытки.
- **Буфер обмена очищается через 30 секунд** после копирования пароля
  или логина (если его не успели заменить).
- **Атомарная запись**: temp-файл + `fsync` + `os.replace`, права `0600`;
  крах или полный диск не могут повредить мастер-ключ или записи.
- **Защита от перезаписи хранилища**: создание поверх существующего
  отклоняется — старые данные больше нельзя случайно уничтожить.
- **Понятные ошибки вместо оракула**: «Invalid password or key file»
  вместо «Invalid padding bytes».
- Удалён неиспользуемый и небезопасный ChaCha20-код.

### Added

- Формат хранилища **v2**: версия (`SPV2`), соль, флаг ключ-файла,
  GCM-blob; любые другие форматы отклоняются при открытии.
- Типизированные исключения: `VaultExistsError`, `VaultNotFoundError`,
  `VaultLockedError`, `InvalidPasswordError`, `TamperError`, `KeyfileError`,
  `DuplicateNameError`, `GroupNotEmptyError`.
- `CHANGELOG.md`.
- `VaultPage`, `GroupDialog`, `PasswordInput` — вынесены из главного окна.
- Ограничение размера ключ-файла (16 МиБ).

### Changed

- **Честный расчёт энтропии**: пул символов по фактическим алфавитам
  (спецсимволы — 26, не 32) и штраф за повторяющиеся символы; `"a"*18`
  больше не проходит порог 80 бит. Для мастер-пароля — минимум 12 символов.
- Главное окно уменьшено почти вдвое: вкладка хранилища, диалоги групп
  и поле пароля стали отдельными компонентами.
- `--debug` теперь реально включает логирование (`propagate` восстановлен).
- Исправлены зависимости: `cryptography>=44.0.0` (нужен для Argon2id),
  удалён неиспользуемый `argon2-cffi`.
- Обновлён README: фактическая схема криптографии, реальные параметры
  Argon2id (64 МиБ / 3 итерации / 4 линии).

### Fixed

- Логи о повреждённых файлах больше не теряются.
- Непустую группу нельзя удалить (записи и подгруппы не «осиротеют»).
- Дочерние виджеты закрытых вкладок и диалогов освобождаются (`deleteLater`).
- Удалён мёртвый код и неиспользуемые импорты.

## [1.0.0] — 2026-07-10

Первый публичный релиз (free-версия).

### Added

- Менеджер паролей с GUI на PySide6: группы, записи, поиск, вкладки.
- Шифрование: Argon2id + AES-256-CBC, мастер-ключ, ключ-файл как 2-й фактор.
- SecureString с попыткой mlock/VirtualLock и занулением.
- Генератор паролей, индикатор надёжности, расчёт энтропии.
- Сборка одним exe через PyInstaller (`secpass-free.exe`).
